# Password Generator

## Project Description
This project is developed using Python for the Auspify Technologies Python Developer Internship.

The Password Generator creates random passwords using letters, numbers, and symbols.

## Features
- Custom password length
- Random password generation
- Letters, numbers, and symbols
- Option to generate multiple passwords
- Input validation

## Technology Used
- Python
- Random module
- String module

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

`python password_generator.py`
